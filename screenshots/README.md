# App Screenshots Directory

This directory holds visual assets and screenshots for the **MobileMaths** portfolio showcase.

## 🖼 Recommended File Naming Convention

To have your screenshots automatically appear in the main `README.md` tables, save your exported device screenshots with the following filenames:

| Filename | Recommended Screen / Flow |
| :--- | :--- |
| `01_auth_login.png` | Login screen with email & password fields |
| `02_auth_signup.png` | Registration screen with form validation |
| `03_auth_verify.png` | Email verification screen with resend countdown |
| `04_home_dashboard.png` | Main student dashboard showing XP level & feature cards |
| `05_elearning_hub.png` | Personalized learning hub with recommended tags |
| `06_video_player.png` | Custom video player in landscape/portrait mode |
| `07_ai_diagnostic.png` | AI Detect 24-question test in progress |
| `08_diagnostic_results.png` | Diagnostic assessment results breakdown |
| `09_speed_math_game.png` | Speed Math 60-second countdown game arena |
| `10_subscription_plans.png` | Subscription tier selection screen |
| `11_payment_hitpay.png` | HitPay PayNow QR checkout screen |
| `12_user_profile.png` | User profile, recent activity history & insights |

## 📐 Recommended Asset Specifications
- **Aspect Ratio**: 9:19.5 or 9:16 (Standard modern smartphone display)
- **Format**: PNG or WebP (Lossless compression recommended)
- **Resolution**: Width ~750px to 1080px for crisp rendering on GitHub displays
